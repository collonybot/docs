---

冒充防護會揪出複製你團隊成員的人：名稱、@使用者名稱或頭像。它也能辨識偽裝過的複製，例如形似字母、差一兩個字母，或裁剪、鏡像的圖片。不涉及 AI，變更會立即儲存。

成員在加入時、修改個人資料時以及每則訊息都會被檢查。在進階檢視中，從 [防護](/zh-Hant/protection) 頁面的 **冒充偵測** 分頁開啟。

## 保護對象

- 專案的擁有者、管理員、版主和團隊成員
- 每個 Telegram 群組的管理員（機器人會自動查找）
- Discord 伺服器工作人員：擁有者和具備管理權限的成員

在 [成員](/zh-Hant/members) 中給團隊裡的其他人指派 **團隊成員** 角色。它不賦予任何權限，但能保護他們不被冒充。機器人看到頭像後才會進行比對。

## 處理方式

每次匹配都會依機器人的確信程度評級。你為每個等級選擇操作。

| 等級 | 情況 |
| --- | --- |
| **確定** | 同時複製了兩項（名稱和頭像，或名稱和 @使用者名稱），或在複製的名稱上加了「Support」、「Admin」之類的字 |
| **可能** | 複製了一項：讀起來相同的名稱或 @使用者名稱，或相同的頭像 |
| **疑似** | 只有讀起來相似的短名稱（4 個字母或更少）。很多成員都可能同名。 |

每個等級可選的操作：**不處理**、**標記待審查**、**刪除訊息 + 標記**、**禁言 + 標記待審查** 或 **封鎖**。

標記會把成員送入 [事件](/zh-Hant/incidents) 頁面的 **待審查**。刪除、禁言和封鎖也會刪除暴露身分的那則訊息。每個冒充者只回報一次。

## 比對項目

選擇什麼算作複製：**名稱**、**@使用者名稱** 和 **頭像**。

- **名稱** 是聊天中顯示的內容：Telegram 上的名和姓，Discord 上的伺服器暱稱和顯示名稱。
- **頭像** 依外觀比對，而不是依檔案。放大或鏡像的副本仍會被辨識。重新儲存、調整尺寸、改變顏色或加邊框都無法隱藏。

## 範例

頁面會展示機器人如何判斷對你某位管理員的複製。以名為 Taylor Quinn（@taylor_quinn）的管理員為例：

| 成員顯示為 | 匹配 |
| --- | --- |
| Taylor Quinn，相同頭像，@tayIor_quinn | 確定 |
| Taylor Quinn \| Support，自己的頭像 | 確定 |
| Talyor Quinn（差一個字母），鏡像頭像 | 確定 |
| 不同名稱，相同頭像放大 | 可能 |
| TayIor Quinn（形似字母） | 可能 |
| Quinn Taylor（字序顛倒） | 可能 |
| Taylor（只有名） | 不匹配 |

<Tip>
  如果你自己的團隊成員被標記，請檢查每個人在 [成員](/zh-Hant/members) 中的角色是否正確。
</Tip>
