成員頁面列出 collony.ai 在目前專案中見過的所有使用者。你可以在這裡管理團隊角色、尋找成員，並同時對多人執行操作。

在頂部選擇時間範圍：24h、7d、30d，或點擊 **更多** 選擇預設或自訂起訖日期。

</Frame>

## 摘要

- 成員數、活躍人數以及與上一週期相比的變化
- 活躍、已禁言和已封鎖的數量
- **每日活躍成員**，以及尖峰日
- **成員發言量**：沉默、1 到 10 則、11 到 50 則、51 則以上
- **依角色**：每個角色有多少成員

## 你的團隊

經營專案的人，依角色分組，以及機器人允許他們做什麼。

| 角色 | 可以做什麼 |
| --- | --- |
| **擁有者** | 完全控制：管理專案、角色、設定和所有管理操作 |
| **管理員** | 管理設定、頻道、內容和版主，並管理使用者 |
| **版主** | 管理內容，禁言和封鎖使用者，刪除訊息，將成員加入白名單，標記團隊成員 |
| **帳單** | 管理方案、付款和連結專案。無管理權限。 |
| **團隊成員** | 無權限。像工作人員一樣受 [冒充防護](/zh-Hant/impersonation) 保護。 |
| **白名單** | 僅跳過惡意內容偵測 |

一個成員可以擁有多個角色，權限會疊加。

<Warning>
  在這裡為你真正的管理員、版主和其他團隊成員指派角色。[冒充防護](/zh-Hant/impersonation) 依靠這些角色區分你的團隊和冒充他們的帳號。
</Warning>

## 成員清單

每列顯示成員、其角色、狀態（活躍、安靜、已禁言、已封鎖）、時間範圍內的訊息、被刪佔比、事件以及最後出現時間。

### 篩選器

- 分頁：**全部**、**活躍**、**工作人員**、**白名單**、**已禁言**、**已封鎖**、**待審查**
- **角色**：任一角色或某一角色。**排序：工作人員優先** 會把你的團隊放在最上方。
- **平台**：全部平台、Telegram 或 Discord
- 依 @使用者名稱或顯示名稱搜尋

### 操作

開啟某列的 **操作** 選單，可以開啟個人資料、設定或移除角色、禁言、封鎖或解除封鎖。

要同時對多個成員操作，選取他們後使用 **新增角色**、**移除角色**、**禁言**、**解除禁言**、**封鎖** 或 **解除封鎖**。

你也可以在聊天中用 `/whitelist` 和 `/unwhitelist` 管理白名單。請參閱 [聊天指令](/zh-Hant/chat-commands)。

<Tip>
  把已驗證的合作夥伴和經常被檢查擋下的資深貢獻者加入白名單。他們可以自由發言，其他人依然受到完整保護。
</Tip>

點擊成員即可開啟其 [個人資料](/zh-Hant/member-details)。
