驗證會在新加入的人發言前先檢查他們。在[防護](/zh-Hant/protection)頁面的 **Verification** 分頁開啟並啟用它。它支援 Telegram 和 Discord，包含在所有方案中，免費版也有。

驗證把機器人和一次性帳號擋在門外。它不判斷已驗證成員之後的行為，那是 [AI 規則](/zh-Hant/ai-rules)、[冒充偵測](/zh-Hant/impersonation)和 [Surge Guard](/zh-Hant/surge-guard) 的工作。

## 預設

選擇一個預設，或用 **Custom** 自己組合步驟。

| 預設 | 新成員需要做什麼 |
| --- | --- |
| **Light** | 點一下。 |
| **Easy** | 通過一次無感的 Cloudflare 檢查。 |
| **Standard** | Cloudflare 檢查，再同意你的規則。 |
| **Strict** | Standard，再加一個圖片拼圖。 |
| **Fortress** | Strict，再加帳號年齡門檻和一個問題。 |
| **Custom** | 只有你選的步驟。 |

使用 **Custom** 時從以下步驟中選擇。無論你以什麼順序勾選，它們總按同一順序執行。

- **帳號年齡**：帳號至少註冊 1、3、7、14、30 或 90 天。
- **點擊**：點一下繼續。
- **Cloudflare 檢查**：無感的檢查，過濾腳本帳號。
- **圖片拼圖**：要解開的視覺拼圖。
- **問題**：你自己的問題，配 2 到 6 個選項。
- **規則**：成員要同意的最多 15 條簡短規則。它們與 [AI 規則](/zh-Hant/ai-rules)中的社群規則是分開的。

## 檢查誰

- **Everyone**：每個新成員都要驗證。
- **Risky only**：只檢查機器人標記為有風險的帳號，其他人直接加入。

## 時限和失敗

| 設定 | 選項 |
| --- | --- |
| **通過時限** | 1、2、5、10 或 30 分鐘，1 小時或 24 小時 |
| **允許答錯次數** | 1 到 5 |
| **未通過時** | **Remove**（可以重新加入）、**Ban** 或 **Wait**（等管理員決定） |

## 驗證訊息

可以寫自己的驗證訊息，也可以用預設訊息。`{name}`、`{chat}` 和 `{time}` 會為每位成員自動填入。開啟清理後，驗證完成會刪除這條訊息。

## Discord 設定

在 Discord 上，等待驗證的成員會被掛上 **Unverified** 身分組，並在驗證頻道裡點 **Verify**。機器人可以替你建立身分組和驗證頻道，並設定所有頻道的權限。它需要「管理身分組」權限，建立頻道還需要「管理頻道」權限。

手動設定：

<Steps>
  <Step title="建立身分組">
    在 Discord 中開啟 **伺服器設定** > **身分組**，建立名為 Unverified 的身分組。
  </Step>
  <Step title="鎖住其他頻道">
    除驗證頻道外的每個頻道，開啟 **編輯頻道** > **權限**，對 @Unverified 禁止 **傳送訊息**。
  </Step>
  <Step title="開放驗證頻道">
    在驗證頻道中，允許 @Unverified **檢視頻道**。
  </Step>
  <Step title="選擇身分組">
    在 **Verification** 分頁的 **Hold with** 中選擇這個身分組。
  </Step>
</Steps>

選擇被暫留的成員能看到什麼：**整個伺服器唯讀**，或**只看得到驗證頻道**。

<Warning>
  如果 **Hold with** 留空，成員會被禁言（timeout）暫留。被禁言的成員無法點按鈕，只能透過私訊驗證，關閉私訊的成員無法通過。請選擇一個身分組來避免這種情況。
</Warning>
