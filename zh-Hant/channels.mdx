頻道頁面依平台分組，列出機器人在目前專案中能看到的所有頻道。你可以為每個頻道選擇是否開啟機器人，以及該頻道的角色。

在關閉的頻道中，機器人不會讀取、管理或回覆。它仍留在群組或伺服器中，但不做任何事。

## 頻道角色

| 角色 | 防護 | 回覆 |
| --- | --- | --- |
| **社群聊天**（預設）：成員交流的地方。機器人保護聊天並回答問題。 | 是 | 是 |
| **僅安全**：機器人刪除垃圾訊息和詐騙、禁言和封鎖，但從不回覆。 | 是 | 否 |
| **僅聊天和支援**：機器人回答問題和聊天，不在這裡進行管理。 | 否 | 是 |
| **管理員通知**：給管理員用的私人頻道。機器人在這裡發布它刪除、禁言或封鎖的報告。 | 否 | 發布報告 |

點擊頻道旁邊的角色即可變更。在機器人會回覆的頻道中，回覆也受 [排程](/zh-Hant/schedule) 和 [偏好設定](/zh-Hant/settings) 中聊天開關的控制。

<Tip>
  把公告頻道和閒聊頻道設為 **僅安全**，機器人會保持它們乾淨而不參與對話。為團隊建立一個私人頻道並設為 **管理員通知**，即可即時掌握機器人的操作。
</Tip>

## 開啟和關閉頻道

在頻道所在列開啟或關閉它。要一次變更多個頻道，選取它們後使用 **設定角色…**、**開啟** 或 **關閉**。

## 新頻道

**新頻道** 設定控制機器人之後發現的頻道，例如新建立的 Discord 頻道：

- **在新頻道中開啟機器人**：關閉時，新頻道會留在此頁面等待，直到你手動開啟。
- **新頻道的角色**：新頻道獲得的角色，預設是社群聊天。

## 篩選器

依 **角色** 和 **機器人權限**（完整權限、受限、無權限、尚未檢查）篩選清單。每列也會顯示頻道類型和最近活躍時間。

<Warning>
  **受限** 或 **無權限** 的頻道缺少機器人需要的權限。在你修正機器人在平台上的權限之前，那裡的管理操作可能會失敗。
</Warning>
