稽核紀錄記錄專案中的每一次變更：來自你的團隊、機器人以及 [AI 應用程式](/zh-Hant/ai-apps)。用它查看誰在什麼時候改了什麼。

## 篩選器

| 篩選器 | 選項 |
| --- | --- |
| **包含機器人操作** | 顯示機器人自行執行的操作，例如 Surge Guard 開啟 |
| **包含 AI 應用程式讀取** | 顯示 AI 應用程式讀取了什麼，而不僅是修改了什麼 |
| **類別** | 全部、帳單、內容、管理、讀取、角色、排程、設定 |
| **操作者** | 所有做過變更的人，包括 collony.ai 團隊 |
| **途徑** | 任一，或僅 AI 應用程式 |
| **時間** | 全部、24h、7d、30d，或點擊 **更多** 選擇預設或自訂起訖日期 |
| **排序** | 最新優先或最早優先 |

## 紀錄

每筆紀錄顯示時間、操作者、操作、對象（使用者、頻道、設定或內容項目）、詳情以及是否成功。點擊紀錄可查看它做的所有事情，失敗時也會顯示錯誤。

透過 AI 應用程式所做的變更會標註 **透過** 該應用程式，例如「透過 Claude（AI 應用程式）」。點擊 **撤銷此變更** 即可還原。

會被記錄的內容範例：

- 新增或移除角色
- 排程、設定和防護的變更
- 在 [機器人設定](/zh-Hant/bot-setup) 中儲存的內容
- 禁言、封鎖和其他管理操作
- 機器人開啟或調整 Surge Guard

<Tip>
  如果機器人的行為發生變化，先依 **內容** 或 **設定** 篩選。通常是最近修改了代理人個性或知識庫。
</Tip>
