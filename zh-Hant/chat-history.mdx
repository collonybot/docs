聊天紀錄是 collony.ai 在目前專案中看到的所有訊息的即時可搜尋動態。每則訊息都帶有情緒分數和話題標籤，你可以直接在頁面上處理。

<Frame>
  ![聊天紀錄頁面，包括篩選器、排程訊息和即時訊息動態](/images/app/chat-history.png)
</Frame>

## 即時動態

動態會自動重新整理。分頁隱藏時會暫停，並在重試時顯示提示。**全部翻譯為英文** 會翻譯整個動態。

## 篩選器

| 篩選器 | 選項 |
| --- | --- |
| **頻道** | 全部頻道或單一頻道，依 Discord 和 Telegram 分組，並顯示訊息數 |
| **顯示** | 全部、已管理、提問、機器人回覆、負面情緒、含媒體 |
| **時間範圍** | 全部時間、24h、7d、30d，或點擊 **更多** 選擇預設或自訂起訖日期 |
| **話題** | 提問、技術、社交、迷因、喊單、FUD、諷刺、髒話 |
| **媒體** | 圖片、影片、GIF、文件、語音、音訊、貼圖、轉傳、聯絡人、投票、位置、限時動態 |

使用搜尋框尋找成員或訊息內容。點擊 **匯出 CSV** 下載篩選結果。

## 訊息操作

開啟任一訊息的選單，可以：

- **開啟訊息**，進入其 [詳情頁](/zh-Hant/message)
- **在 Telegram 中開啟** 或在 Discord 中開啟
- **複製連結** 或 **複製文字**
- **查看成員**，開啟其 [個人資料](/zh-Hant/member-details)
- **禁言** 24 小時（預設）、1 小時或 7 天
- **封鎖** 傳送者
- **刪除訊息**

展開訊息可查看其標籤和表情回應。

<Warning>
  在應用程式中執行的操作會立即在社群中生效。
</Warning>

## 以 collony 身分傳送

點擊 **以 collony 身分傳送**，以機器人身分在頻道中立即或排程發布訊息。

排程訊息和最近傳送的訊息顯示在動態上方：頻道、時間、傳送者以及傳送方式（來自應用程式、[助理](/zh-Hant/assistant) 或 [AI 應用程式](/zh-Hant/ai-apps)）。排程訊息可以編輯或取消。如果訊息傳送失敗，例如機器人已被移出聊天，會顯示錯誤，你可以點擊 **重新傳送**。
