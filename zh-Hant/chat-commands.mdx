---
title: "聊天指令"
description: "直接在 Telegram 群組或 Discord 伺服器中使用 /mute、/ban、/fp 等指令進行管理。"
---

無需開啟應用程式，直接在社群聊天中進行管理。指令在專案連結的所有 Telegram 群組和 Discord 伺服器中都可使用。應用程式的 **指南** 頁面也有同樣的清單。

## 誰可以使用

專案擁有者、管理員和版主。平台上的聊天管理員也可以。其他人會收到一則簡短的「僅限管理員」回覆，幾秒後自動刪除。

- **Discord**：原生斜線指令。輸入 `/`，從 Discord 選單中選擇指令，並用使用者選擇器選擇對象。只有你能看到回覆。也可以作為一般文字輸入。
- **Telegram**：群組管理員在 `/` 自動完成選單中看到相同的指令。

## 指令

| 指令 | 別名 | 作用 | 範例 |
| --- | --- | --- | --- |
| `/whitelist` | `/wl` | 將使用者加入白名單。其訊息跳過惡意內容偵測。 | 回覆 `/whitelist` |
| `/unwhitelist` | `/unwl` | 移除白名單角色 | `/unwhitelist @username` |
| `/role` | `/roles` | 顯示使用者在專案中的角色 | `/role @username` |
| `/mute` |  | 禁言使用者。可加時長（`30m`、`2h`、`1d`），不加則永久禁言。 | `/mute @username 2h` |
| `/unmute` |  | 解除禁言 | 回覆 `/unmute` |
| `/ban` |  | 封鎖使用者。Telegram 上可設時長（`1d`）。Discord 封鎖始終為永久。 | `/ban @username` |
| `/unban` |  | 解除封鎖 | `/unban @username` |
| `/unrestrict` |  | 解除所有限制（解除禁言和封鎖） | 回覆 `/unrestrict` |
| `/forgive` |  | 清除使用者的警告，結束其生效中的事件，並解除禁言或封鎖 | 回覆 `/forgive` |
| `/falsepositive` | `/fp` | 將使用者最近的事件標記為 collony.ai 誤判，撤銷其操作並解除禁言或封鎖 | 回覆 `/fp` |
| `/userstats` | `/stats` | 快速摘要：傳送的訊息、警告、首次和最後出現時間、7 天情緒 | `/userstats @username` |

## 指定對象使用者

在 Discord 上，斜線指令會彈出使用者選擇器。文字指令依以下順序尋找使用者：

1. **回覆** 其一則訊息。這是最可靠的方式，即使對方沒有使用者名稱也能用。
2. **提及** 對方：Telegram 上用 `@username`，Discord 上用一般提及。

<Tip>
  在 Telegram 手機版，點擊 `/` 選單中的指令會立即傳送。請先滑動回覆該使用者的訊息，再點擊指令。
</Tip>

機器人必須至少見過該使用者一次，即對方在連結的聊天中發過訊息。否則機器人還無法辨識對方。

## 與其他機器人並存

在同一群組中使用 Rose、Combot 或類似機器人？發給其他機器人的指令（例如 `/stats@combot`）會被忽略。如果一個不帶後綴的指令同時觸發兩個機器人，請直接指定 collony.ai，例如 `/userstats@CollonyBot`，或使用不衝突的別名。
