封鎖清單在 AI 讀取訊息之前就即時處理字詞、片語和連結。在進階檢視中，從 [防護](/zh-Hant/protection) 頁面的 **封鎖清單** 分頁開啟。簡單檢視以更簡短的形式顯示同樣的清單。

分頁頂部顯示封鎖清單最近 7 天攔截了什麼，以及哪些清單命中。

<Frame>
  ![封鎖清單分頁，包括封鎖網域、允許網域和合集](/images/app/blocklists.png)
</Frame>

## 命中後的處理

你可以為每個網域、合集或項目選擇命中時的操作：

| 操作 | 結果 |
| --- | --- |
| **預設** | 使用該清單的預設操作 |
| **僅標記** | 保留訊息，將其加入 **待審查**，並讓 AI 也檢查一次 |
| **刪除** | 刪除訊息 |
| **刪除 + 標記** | 刪除訊息並加入待審查 |
| **刪除 + 禁言** | 刪除訊息並禁言成員 |
| **刪除 + 禁言 + 標記** | 以上全部 |
| **封鎖** | 移除成員 |

## 保持 collony.ai 清單最新

開啟後，collony.ai 新增或停用的字詞和網域會自動套用到你的專案。關閉時，每次更新都會留在此頁面等待你審查。

## 封鎖網域

指向這些網域及其所有子網域的連結會被即時處理。輸入網域並點擊 **封鎖**。collony.ai 新增的網域會有標註。

## 允許網域

這裡的網域永遠不會被封鎖：你的網站、文件、合作夥伴。允許網域優先於所有封鎖網域以及 [新成員連結限制](/zh-Hant/enforcement)。輸入網域並點擊 **允許**。

<Tip>
  在收緊連結規則之前，先把官方連結加入允許網域，這樣機器人就不會刪除你自己的公告。
</Tip>

## 合集

collony.ai 替你維護的清單。開啟一個合集，選擇命中後的操作，並新增你自己的項目。

| 合集 | 攔截內容 | 預設操作 |
| --- | --- | --- |
| **Known scam sources** | 在其他社群轉發貼文和限時動態時被證實為詐騙的使用者和頻道 | 刪除 + 禁言 |
| **Crypto scams** | 虛假空投、錢包盜取器、保證收益和「資金追回」騙局 | 刪除 + 禁言 |
| **Contact-me / DM scams** | 假客服、「私訊我獲得協助」、付費訊號 | 刪除 |
| **Adult spam** | 成人內容推廣以及直播或交友垃圾連結 | 刪除 + 禁言 |
| **Link shorteners** | 隱藏真實位址的短網址，常被用來逃避審查 | 刪除 |
| **Slurs** | 種族、民族、恐同、恐跨和歧視身心障礙的辱罵詞，包括變體拼寫 | 刪除 |

每個合集顯示其生效項目、其中有多少是你新增的、最近 7 天的命中次數以及命中最多的項目。

### 你的項目

向任何合集新增你自己的 **字詞**、**片語** 或 **網域**，並設定個別操作，或點擊 **匯入檔案** 一次新增多個。用 **移除** 刪除項目。

**collony.ai 項目** 清單顯示 collony.ai 在該合集中維護的內容。任何合集都可匯出為 JSON、CSV 或 TXT。
