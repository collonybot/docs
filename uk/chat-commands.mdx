Модеруйте прямо з чату спільноти, не відкриваючи застосунок. Команди працюють у всіх групах Telegram і на всіх серверах Discord, підключених до проєкту. Той самий список є на сторінці **Посібник** у застосунку.

## Хто може їх використовувати

Власники, адміни і модератори проєкту. Адміни чату на платформі теж рахуються. Усі інші отримують коротку відповідь «лише для адмінів», яка зникає за кілька секунд.

- **Discord**: вбудовані слеш-команди. Введіть `/`, оберіть команду в меню Discord і вкажіть учасника через вибір користувача. Відповідь бачите лише ви. Можна також вводити їх звичайним текстом.
- **Telegram**: адміни групи бачать ті самі команди в меню автодоповнення `/`.

## Команди

| Команда | Синонім | Що робить | Приклад |
| --- | --- | --- | --- |
| `/whitelist` | `/wl` | Додає користувача у вайтлист. Його повідомлення не перевіряються на шкідливий контент. | Відповіддю `/whitelist` |
| `/unwhitelist` | `/unwl` | Прибирає роль вайтлиста | `/unwhitelist @username` |
| `/role` | `/roles` | Показує ролі користувача в проєкті | `/role @username` |
| `/mute` |  | Мутить користувача. Додайте тривалість (`30m`, `2h`, `1d`) або залиште порожнім для постійного муту. | `/mute @username 2h` |
| `/unmute` |  | Знімає мут | Відповіддю `/unmute` |
| `/ban` |  | Банить користувача. Тривалість працює в Telegram (`1d`). Бани в Discord завжди постійні. | `/ban @username` |
| `/unban` |  | Знімає бан | `/unban @username` |
| `/unrestrict` |  | Знімає всі обмеження (мут і бан) | Відповіддю `/unrestrict` |
| `/forgive` |  | Очищає попередження, закриває активні інциденти та знімає мут чи бан | Відповіддю `/forgive` |
| `/falsepositive` | `/fp` | Позначає останній інцидент як помилку collony.ai, скасовує його дії та знімає мут чи бан | Відповіддю `/fp` |
| `/userstats` | `/stats` | Коротке зведення: повідомлення, попередження, перша й остання поява, настрій за 7 днів | `/userstats @username` |

## Як вказати користувача

У Discord слеш-команди просять обрати користувача зі списку. Текстові команди шукають користувача в такому порядку:

1. **Відповідь** на одне з його повідомлень. Це найнадійніший спосіб, він працює навіть без юзернейму.
2. **Згадка**: `@username` у Telegram, звичайна згадка в Discord.

<Tip>
  У мобільному Telegram натискання команди в меню `/` одразу її надсилає. Спершу свайпніть повідомлення користувача для відповіді, а потім натисніть команду.
</Tip>

Бот має хоча б раз бачити користувача, тобто той має написати в підключеному чаті. Інакше бот ще не може його визначити.

## Робота поруч із іншими ботами

Використовуєте Rose, Combot чи подібного бота в тій самій групі? Команди, адресовані іншому боту, наприклад `/stats@combot`, ігноруються. Якщо команда без адресата спрацьовує у двох ботів одночасно, звертайтеся до collony.ai напряму, наприклад `/userstats@CollonyBot`, або використовуйте синонім, який не конфліктує.
