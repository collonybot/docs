Модерируйте прямо из чата сообщества, не открывая приложение. Команды работают во всех группах Telegram и на всех серверах Discord, подключённых к проекту. Тот же список есть на странице **Руководство** в приложении.

## Кто может их использовать

Владельцы, админы и модераторы проекта. Админы чата на платформе тоже считаются. Все остальные получают короткий ответ «только для админов», который исчезает через несколько секунд.

- **Discord**: встроенные слеш-команды. Введите `/`, выберите команду в меню Discord и укажите участника через выбор пользователя. Ответ видите только вы. Можно также вводить их обычным текстом.
- **Telegram**: админы группы видят те же команды в меню автодополнения `/`.

## Команды

| Команда | Синоним | Что делает | Пример |
| --- | --- | --- | --- |
| `/whitelist` | `/wl` | Добавляет пользователя в вайтлист. Его сообщения не проверяются на вредоносный контент. | Ответом `/whitelist` |
| `/unwhitelist` | `/unwl` | Убирает роль вайтлиста | `/unwhitelist @username` |
| `/role` | `/roles` | Показывает роли пользователя в проекте | `/role @username` |
| `/mute` |  | Мутит пользователя. Добавьте срок (`30m`, `2h`, `1d`) или оставьте пустым для постоянного мута. | `/mute @username 2h` |
| `/unmute` |  | Снимает мут | Ответом `/unmute` |
| `/ban` |  | Банит пользователя. Срок работает в Telegram (`1d`). Баны в Discord всегда постоянные. | `/ban @username` |
| `/unban` |  | Снимает бан | `/unban @username` |
| `/unrestrict` |  | Снимает все ограничения (мут и бан) | Ответом `/unrestrict` |
| `/forgive` |  | Очищает предупреждения, закрывает активные инциденты и снимает мут или бан | Ответом `/forgive` |
| `/falsepositive` | `/fp` | Отмечает последний инцидент как ошибку collony.ai, отменяет его действия и снимает мут или бан | Ответом `/fp` |
| `/userstats` | `/stats` | Краткая сводка: сообщения, предупреждения, первое и последнее появление, настроение за 7 дней | `/userstats @username` |

## Как указать пользователя

В Discord слеш-команды просят выбрать пользователя из списка. Текстовые команды ищут пользователя в таком порядке:

1. **Ответ** на одно из его сообщений. Это самый надёжный способ, он работает даже без юзернейма.
2. **Упоминание**: `@username` в Telegram, обычное упоминание в Discord.

<Tip>
  В мобильном Telegram нажатие на команду в меню `/` сразу её отправляет. Сначала свайпните сообщение пользователя для ответа, а затем нажмите команду.
</Tip>

Бот должен хотя бы раз видеть пользователя, то есть тот должен написать в подключённом чате. Иначе бот пока не может его определить.

## Работа рядом с другими ботами

Используете Rose, Combot или похожего бота в той же группе? Команды, адресованные другому боту, например `/stats@combot`, игнорируются. Если команда без адресата срабатывает у двух ботов сразу, обращайтесь к collony.ai напрямую, например `/userstats@CollonyBot`, или используйте синоним, который не конфликтует.
