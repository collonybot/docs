Allez sur [app.collony.ai](https://app.collony.ai/login) et connectez-vous avec l'une de ces trois options :

- **Continuer avec Discord**
- **Continuer avec Google**
- **Continuer avec Telegram**

Toutes les options fonctionnent, quelles que soient les plateformes que vous modérez. Si vous avez déjà utilisé collony.ai, connectez-vous avec la même option qu'avant.

Vous pouvez changer la langue de l'app dans le menu des langues : anglais, espagnol, français, hindi, ukrainien, chinois (traditionnel et simplifié) ou russe.

## Liez vos comptes

Liez Telegram, Discord et Google à un seul compte pour voir toutes vos communautés au même endroit. Cliquez sur votre nom en haut à droite pour ouvrir la page **Compte**. Sous **Comptes liés**, connectez une plateforme pour vous connecter avec elle et gérer les projets que vous y avez.

La page Compte liste aussi les [apps IA](/fr/ai-apps) que vous avez connectées, avec leur accès, leurs projets et leur expiration.

### Lier Telegram

Cliquez sur **Lier avec Telegram**.

<Warning>
  Si Telegram vous connecte mais que l'app Telegram ne garde pas la session, ouvrez collony.ai dans votre navigateur pour continuer. Si la liaison échoue parce que Telegram n'est pas installé sur votre ordinateur, liez votre compte manuellement.
</Warning>

Pour lier manuellement :

1. Ouvrez [@CollonyBot](https://t.me/CollonyBot) sur Telegram.
2. Envoyez `/linkweb`.
3. Cliquez sur le lien que le bot renvoie. Il expire au bout de 5 minutes.

Une fois liés, vos groupes Telegram apparaissent sur la page Projets et dans le sélecteur de projets.

### Lier Discord

Connectez-vous avec Discord, ou cliquez sur **Lier avec Discord** sur votre page de compte. Vous pourrez ensuite revendiquer et gérer les serveurs où le bot est installé.
