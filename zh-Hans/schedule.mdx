时间表页面设置机器人做什么以及何时做。你可以全天候进行管理，同时把聊天回复限制在社区最活跃的时段。

<Frame>
  ![时间表页面，包括时间表选项、时区和每周网格](/images/app/schedule.png)
</Frame>

## 机器人已开启

总开关。关闭时，无论时间表如何设置，机器人都不做任何事。

## 选择时间表

| 选项 | 机器人做什么 |
| --- | --- |
| **Always Security** | 每天每小时都进行管理，不回复聊天 |
| **Always Chat + Security** | 全天候管理并在聊天中回复 |
| **Custom** | 你自己选择时段以及每个时段的模式 |

页面会显示当前模式以及下一次切换的时间。

## 时区

时间按时间表时区显示。从列表中选择，从 UTC-10（檀香山）到 UTC+12（奥克兰），让网格与社区的作息一致。

## 自定义时间表

选择一个模式，然后在每周网格上涂色：

| 模式 | 机器人做什么 |
| --- | --- |
| **Security** | 进行管理，但不回复也不参与对话 |
| **Chat + Security** | 管理并回复：聊天、FAQ 回答和表情回应 |
| **Off** | 该时段不做任何事 |

1. 在网格上拖动，以 30 分钟为单位涂色。
2. 点击星期名称填满当天，或点击小时标签填满每天的该小时。
3. 点击 **保存更改**，或点击 **放弃** 撤销。

<Tip>
  常见设置：社区高峰时段用 Chat + Security，其余时间用 Security。诈骗仍会被全天候删除，而机器人只在有人在线时聊天。
</Tip>
