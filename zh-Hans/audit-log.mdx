审计日志记录项目中的每一次更改：来自你的团队、机器人以及 [AI 应用](/zh-Hans/ai-apps)。用它查看谁在什么时候改了什么。

<Frame>
  ![审计日志，包括筛选器以及来自团队、机器人和 AI 应用的记录](/images/app/audit-log.png)
</Frame>

## 筛选器

| 筛选器 | 选项 |
| --- | --- |
| **包含机器人操作** | 显示机器人自行执行的操作，例如 Surge Guard 开启 |
| **包含 AI 应用读取** | 显示 AI 应用读取了什么，而不仅是修改了什么 |
| **类别** | 全部、账单、内容、管理、读取、角色、时间表、设置 |
| **操作人** | 所有做过更改的人，包括 collony.ai 团队 |
| **途径** | 任意，或仅 AI 应用 |
| **时间** | 全部、24h、7d、30d，或点击 **更多** 选择预设或自定义起止日期 |
| **排序** | 最新优先或最早优先 |

## 记录

每条记录显示时间、操作人、操作、对象（用户、频道、设置或内容项）、详情以及是否成功。点击记录可查看它做的所有事情，失败时还会显示错误。

通过 AI 应用所做的更改会标注 **通过** 该应用，例如“通过 Claude（AI 应用）”。点击 **撤销此更改** 即可还原。

会被记录的内容示例：

- 添加或移除角色
- 时间表、设置和防护的更改
- 在 [机器人设置](/zh-Hans/bot-setup) 中保存的内容
- 禁言、封禁和其他管理操作
- 机器人开启或调整 Surge Guard

<Tip>
  如果机器人的行为发生变化，先按 **内容** 或 **设置** 筛选。通常是最近修改了智能体性格或知识库。
</Tip>
