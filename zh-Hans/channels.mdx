频道页面按平台分组，列出机器人在当前项目中能看到的所有频道。你可以为每个频道选择是否开启机器人，以及该频道的角色。

在关闭的频道中，机器人不会读取、管理或回复。它仍留在群组或服务器中，但不做任何事。

## 频道角色

| 角色 | 防护 | 回复 |
| --- | --- | --- |
| **社区聊天**（默认）：成员交流的地方。机器人保护聊天并回答问题。 | 是 | 是 |
| **仅安全**：机器人删除垃圾信息和诈骗、禁言和封禁，但从不回复。 | 是 | 否 |
| **仅聊天和支持**：机器人回答问题和聊天，不在这里进行管理。 | 否 | 是 |
| **管理员通知**：给管理员用的私密频道。机器人在这里发布它删除、禁言或封禁的报告。 | 否 | 发布报告 |

点击频道旁边的角色即可更改。在机器人会回复的频道中，回复还受 [时间表](/zh-Hans/schedule) 和 [设置](/zh-Hans/settings) 中聊天开关的控制。

<Tip>
  把公告频道和闲聊频道设为 **仅安全**，机器人会保持它们干净而不参与对话。为团队创建一个私密频道并设为 **管理员通知**，即可实时了解机器人的操作。
</Tip>

## 开启和关闭频道

在频道所在行开启或关闭它。要一次更改多个频道，选中它们后使用 **设置角色…**、**开启** 或 **关闭**。

## 新频道

**新频道** 设置控制机器人之后发现的频道，例如新建的 Discord 频道：

- **在新频道中开启机器人**：关闭时，新频道会留在此页面等待，直到你手动开启。
- **新频道的角色**：新频道获得的角色，默认是社区聊天。

## 筛选器

按 **角色** 和 **机器人权限**（完全权限、受限、无权限、尚未检查）筛选列表。每行还显示频道类型和最近活跃时间。

<Warning>
  **受限** 或 **无权限** 的频道缺少机器人需要的权限。在你修复机器人在平台上的权限之前，那里的管理操作可能会失败。
</Warning>
