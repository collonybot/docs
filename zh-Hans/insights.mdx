洞察展示你的社区在所选时间段内的感受和交流方式。它有两种视图：**简单** 和 **高级**，可在页面顶部切换。

在顶部选择时间范围：24h、7d、30d，或点击 **更多** 选择其他预设和自定义日期。

## 简单视图

在一个页面上以卡片形式呈现社区全貌：

| 卡片 | 显示内容 |
| --- | --- |
| **情绪** | -100 到 +100 的分数、一句简述（例如“以正面为主”）、与上一周期相比的变化，以及正面、中性和负面的分布 |
| **消息** | 成员消息数、与上一周期相比的变化和每日条形图 |
| **发言者** | 聊天中有多少成员发言，分为常客、回归者和新人 |
| **提问** | collony AI 回答了多少问题，以及回答速度 |
| **最佳发帖时间** | 该时间段内最繁忙的小时（UTC） |
| **最受欢迎的消息** | 收到回应最多的消息，以及谁做了回应 |
| **最爱表情** | 最常用的表情及其后几名 |
| **连续天数** | 连续有消息的天数 |
| **本周人物** | 最活跃的成员、最积极的声音，以及值得关注的人（情绪最低） |

### 大家在聊什么

- **话题**：按话题划分的消息占比，例如社交、技术、提问、脏话和讽刺，以及变化最大的话题
- **未回答**：最近没有人回答的问题。点击 **改进回答** 将它们加入知识库。
- **最活跃频道**：按频道划分的消息占比

<Tip>
  **未回答** 中反复出现的问题是最快的改进点。把答案加入 [知识库](/zh-Hans/bot-setup)，下次机器人就能自己回答。
</Tip>

### 成长

新加入的成员以及成员分布情况，按 Telegram 和 Discord 划分，并显示各平台的消息占比。

## 高级视图

高级视图顶部显示每日情绪、成员消息、表情回应、机器人回复、被删消息，以及有多少成员发言或仅做了回应。下方有六个标签。

<Tabs>
  <Tab title="概览">
    社区的活跃程度。

    - **活动时间线**：实时显示消息随时间的变化，可缩放 1h 至 30d。在图表上拖动可放大。阴影带表示 [Surge Guard](/zh-Hans/surge-guard) 慢速模式开启的时段。
    - **每日活跃成员**：每天发消息的和仅做回应的成员
    - **提问与助手**：由 collony AI 回答、由成员回答或无人回答的问题占比、平均回答时间和每日回答时间
  </Tab>
  <Tab title="成员">
    谁发言最多、谁的消息收到回应、谁在回应。

    - **参与度**：从聊天成员到回应者、发言者、收到回应者以及受欢迎者（5 个及以上回应）的漏斗，并与上一周期对比
    - **成员地图**：每位成员按消息数和情绪分布，大小反映收到的回应
    - **最活跃**、**收到回应最多** 和 **回应最多** 排行

    点击成员即可打开其 [资料](/zh-Hans/member-details)。
  </Tab>
  <Tab title="回应">
    社区最喜欢的消息、谁在何时做了回应，以及成员最爱的表情。
  </Tab>
  <Tab title="情绪">
    聊天的情绪，逐条消息评分。

    - 正面、中性和负面占比及消息数，以及净情绪
    - **情绪趋势**，包括净情绪范围和最繁忙的一天
    - **最积极的成员** 和 **最消极的成员**，附带消息数和平均分

    <Tip>
      同一账号持续消极往往是麻烦的前兆。在变成事件之前先看看这些成员。
    </Tip>
  </Tab>
  <Tab title="节奏">
    社区何时活跃（UTC）：最近几周的日历、最繁忙的一天和星期几、最长连续天数、按星期和小时划分的活动，以及日期和小时的热力图。

    用它安排公告和 AMA 的时间，并设置你的 [时间表](/zh-Hans/schedule)。
  </Tab>
  <Tab title="消息">
    数字背后的已评分消息，让你可以读到成员实际说了什么。
  </Tab>
</Tabs>
