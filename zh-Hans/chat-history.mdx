聊天记录是 collony.ai 在当前项目中看到的所有消息的实时可搜索动态。每条消息都带有情绪分数和话题标签，你可以直接在页面上处理。

<Frame>
  ![聊天记录页面，包括筛选器、定时消息和实时消息动态](/images/app/chat-history.png)
</Frame>

## 实时动态

动态会自动刷新。标签页隐藏时会暂停，并在重试时显示提示。**全部翻译为英文** 会翻译整个动态。

## 筛选器

| 筛选器 | 选项 |
| --- | --- |
| **频道** | 全部频道或单个频道，按 Discord 和 Telegram 分组，并显示消息数 |
| **显示** | 全部、已管理、提问、机器人回复、负面情绪、含媒体 |
| **时间范围** | 全部时间、24h、7d、30d，或点击 **更多** 选择预设或自定义起止日期 |
| **话题** | 提问、技术、社交、梗图、喊单、FUD、讽刺、脏话 |
| **媒体** | 图片、视频、GIF、文件、语音、音频、贴纸、转发、联系人、投票、位置、快拍 |

使用搜索框查找成员或消息内容。点击 **导出 CSV** 下载筛选结果。

## 消息操作

打开任意消息的菜单，可以：

- **打开消息**，进入其 [详情页](/zh-Hans/message)
- **在 Telegram 中打开** 或在 Discord 中打开
- **复制链接** 或 **复制文本**
- **查看成员**，打开其 [资料](/zh-Hans/member-details)
- **禁言** 24 小时（默认）、1 小时或 7 天
- **封禁** 发送者
- **删除消息**

展开消息可查看其标签和表情回应。

<Warning>
  在应用中执行的操作会立即在社区中生效。
</Warning>

## 以 collony 身份发送

点击 **以 collony 身份发送**，以机器人身份在频道中立即或定时发布消息。

定时消息和最近发送的消息显示在动态上方：频道、时间、发送者以及发送方式（来自应用、[助手](/zh-Hans/assistant) 或 [AI 应用](/zh-Hans/ai-apps)）。定时消息可以编辑或取消。如果消息发送失败，例如机器人已被移出聊天，会显示错误，你可以点击 **重新发送**。
