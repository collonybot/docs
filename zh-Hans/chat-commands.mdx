---
title: "聊天命令"
description: "直接在 Telegram 群组或 Discord 服务器中使用 /mute、/ban、/fp 等命令进行管理。"
---

无需打开应用，直接在社区聊天中进行管理。命令在项目关联的所有 Telegram 群组和 Discord 服务器中都可使用。应用的 **指南** 页面也有同样的列表。

## 谁可以使用

项目所有者、管理员和版主。平台上的聊天管理员也可以。其他人会收到一条简短的“仅限管理员”回复，几秒后自动删除。

- **Discord**：原生斜杠命令。输入 `/`，从 Discord 菜单中选择命令，并用用户选择器选择对象。只有你能看到回复。也可以作为普通文本输入。
- **Telegram**：群组管理员在 `/` 自动补全菜单中看到相同的命令。

## 命令

| 命令 | 别名 | 作用 | 示例 |
| --- | --- | --- | --- |
| `/whitelist` | `/wl` | 将用户加入白名单。其消息跳过恶意内容检测。 | 回复 `/whitelist` |
| `/unwhitelist` | `/unwl` | 移除白名单角色 | `/unwhitelist @username` |
| `/role` | `/roles` | 显示用户在项目中的角色 | `/role @username` |
| `/mute` |  | 禁言用户。可加时长（`30m`、`2h`、`1d`），不加则永久禁言。 | `/mute @username 2h` |
| `/unmute` |  | 解除禁言 | 回复 `/unmute` |
| `/ban` |  | 封禁用户。Telegram 上可设时长（`1d`）。Discord 封禁始终为永久。 | `/ban @username` |
| `/unban` |  | 解除封禁 | `/unban @username` |
| `/unrestrict` |  | 解除所有限制（解除禁言和封禁） | 回复 `/unrestrict` |
| `/forgive` |  | 清除用户的警告，关闭其生效中的事件，并解除禁言或封禁 | 回复 `/forgive` |
| `/falsepositive` | `/fp` | 将用户最近的事件标记为 collony.ai 误判，撤销其操作并解除禁言或封禁 | 回复 `/fp` |
| `/userstats` | `/stats` | 快速概要：发送的消息、警告、首次和最后出现时间、7 天情绪 | `/userstats @username` |

## 指定对象用户

在 Discord 上，斜杠命令会弹出用户选择器。文本命令按以下顺序查找用户：

1. **回复** 其一条消息。这是最可靠的方式，即使对方没有用户名也能用。
2. **提及** 对方：Telegram 上用 `@username`，Discord 上用普通提及。

<Tip>
  在 Telegram 手机端，点击 `/` 菜单中的命令会立即发送。请先滑动回复该用户的消息，再点击命令。
</Tip>

机器人必须至少见过该用户一次，即对方在关联的聊天中发过消息。否则机器人还无法识别对方。

## 与其他机器人共存

在同一群组中使用 Rose、Combot 或类似机器人？发给其他机器人的命令（例如 `/stats@combot`）会被忽略。如果一个不带后缀的命令同时触发两个机器人，请直接指定 collony.ai，例如 `/userstats@CollonyBot`，或使用不冲突的别名。
