成员页面列出 collony.ai 在当前项目中见过的所有用户。你可以在这里管理团队角色、查找成员，并同时对多人执行操作。

在顶部选择时间范围：24h、7d、30d，或点击 **更多** 选择预设或自定义起止日期。

<Frame>
  ![成员页面，包括活跃概要、你的团队面板和成员列表](/images/app/members.png)
</Frame>

## 概要

- 成员数、活跃人数以及与上一周期相比的变化
- 活跃、已禁言和已封禁的数量
- **每日活跃成员**，以及峰值日
- **成员发言量**：沉默、1 到 10 条、11 到 50 条、51 条及以上
- **按角色**：每个角色有多少成员

## 你的团队

运营项目的人，按角色分组，以及机器人允许他们做什么。

| 角色 | 可以做什么 |
| --- | --- |
| **所有者** | 完全控制：管理项目、角色、设置和所有管理操作 |
| **管理员** | 管理设置、频道、内容和版主，并管理用户 |
| **版主** | 管理内容，禁言和封禁用户，删除消息，将成员加入白名单，标记团队成员 |
| **账单** | 管理方案、付款和关联项目。无管理权限。 |
| **团队成员** | 无权限。像工作人员一样受 [冒充防护](/zh-Hans/impersonation) 保护。 |
| **白名单** | 仅跳过恶意内容检测 |

一个成员可以拥有多个角色，权限会叠加。

<Warning>
  在这里为你真正的管理员、版主和其他团队成员分配角色。[冒充防护](/zh-Hans/impersonation) 依靠这些角色区分你的团队和冒充他们的账号。
</Warning>

## 成员列表

每行显示成员、其角色、状态（活跃、安静、已禁言、已封禁）、时间范围内的消息、被删占比、事件以及最后出现时间。

### 筛选器

- 标签：**全部**、**活跃**、**工作人员**、**白名单**、**已禁言**、**已封禁**、**待审核**
- **角色**：任意角色或某一角色。**排序：工作人员优先** 会把你的团队放在最上方。
- **平台**：全部平台、Telegram 或 Discord
- 按 @用户名或显示名称搜索

### 操作

打开某行的 **操作** 菜单，可以打开资料、设置或移除角色、禁言、封禁或解封。

要同时对多个成员操作，选中他们后使用 **添加角色**、**移除角色**、**禁言**、**解除禁言**、**封禁** 或 **解封**。

你也可以在聊天中用 `/whitelist` 和 `/unwhitelist` 管理白名单。参见 [聊天命令](/zh-Hans/chat-commands)。

<Tip>
  把已验证的合作伙伴和经常被检查拦下的老贡献者加入白名单。他们可以自由发言，其他人依然受到完整保护。
</Tip>

点击成员即可打开其 [资料](/zh-Hans/member-details)。
