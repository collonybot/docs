冒充防护会识别复制你团队成员的人：名字、@用户名或头像。它也能识别伪装过的复制，例如形似字母、差一两个字母，或裁剪、镜像的图片。不涉及 AI，更改会立即保存。

成员在加入时、修改资料时以及每条消息都会被检查。在高级视图中，从 [防护](/zh-Hans/protection) 页面的 **冒充检测** 标签打开。

## 保护对象

- 项目的所有者、管理员、版主和团队成员
- 每个 Telegram 群聊的管理员（机器人会自动查找）
- Discord 服务器工作人员：服主和拥有管理权限的成员

在 [成员](/zh-Hans/members) 中给团队里的其他人分配 **团队成员** 角色。它不赋予任何权限，但能保护他们不被冒充。机器人看到头像后才会进行比对。

## 处理方式

每次匹配都会按机器人的确信程度评级。你为每个等级选择操作。

| 等级 | 情况 |
| --- | --- |
| **确定** | 同时复制了两项（名字和头像，或名字和 @用户名），或在复制的名字上加了“Support”、“Admin”之类的词 |
| **可能** | 复制了一项：读起来相同的名字或 @用户名，或相同的头像 |
| **疑似** | 只有读起来相似的短名字（4 个字母或更少）。很多成员都可能重名。 |

每个等级可选的操作：**不处理**、**标记待审核**、**删除消息 + 标记**、**禁言 + 标记待审核** 或 **封禁**。

标记会把成员送入 [事件](/zh-Hans/incidents) 页面的 **待审核**。删除、禁言和封禁还会删除暴露身份的那条消息。每个冒充者只报告一次。

## 比对项

选择什么算作复制：**名字**、**@用户名** 和 **头像**。

- **名字** 是聊天中显示的内容：Telegram 上的名和姓，Discord 上的服务器昵称和显示名称。
- **头像** 按外观比对，而不是按文件。放大或镜像的副本仍会被识别。重新保存、调整尺寸、改变颜色或加边框都无法隐藏。

## 示例

页面会展示机器人如何判断对你某位管理员的复制。以名为 Taylor Quinn（@taylor_quinn）的管理员为例：

| 成员显示为 | 匹配 |
| --- | --- |
| Taylor Quinn，相同头像，@tayIor_quinn | 确定 |
| Taylor Quinn \| Support，自己的头像 | 确定 |
| Talyor Quinn（差一个字母），镜像头像 | 确定 |
| 不同名字，相同头像放大 | 可能 |
| TayIor Quinn（形似字母） | 可能 |
| Quinn Taylor（词序颠倒） | 可能 |
| Taylor（只有名） | 不匹配 |

<Tip>
  如果你自己的团队成员被标记，请检查每个人在 [成员](/zh-Hans/members) 中的角色是否正确。
</Tip>
