屏蔽列表在 AI 读取消息之前就即时处理词语、短语和链接。在高级视图中，从 [防护](/zh-Hans/protection) 页面的 **屏蔽列表** 标签打开。简单视图以更简短的形式显示同样的列表。

标签页顶部显示屏蔽列表最近 7 天拦截了什么，以及哪些列表命中。

  ![屏蔽列表标签页，包括屏蔽域名、允许域名和合集](/images/app/blocklists.png)

## 命中后的处理

你可以为每个域名、合集或条目选择命中时的操作：

| 操作 | 结果 |
| --- | --- |
| **默认** | 使用该列表的默认操作 |
| **仅标记** | 保留消息，将其加入 **待审核**，并让 AI 也检查一遍 |
| **删除** | 删除消息 |
| **删除 + 标记** | 删除消息并加入待审核 |
| **删除 + 禁言** | 删除消息并禁言成员 |
| **删除 + 禁言 + 标记** | 以上全部 |
| **封禁** | 移除成员 |

## 保持 collony.ai 列表最新

开启后，collony.ai 新增或停用的词语和域名会自动应用到你的项目。关闭时，每次更新都会留在此页面等待你审核。

## 屏蔽域名

指向这些域名及其所有子域名的链接会被即时处理。输入域名并点击 **屏蔽**。collony.ai 添加的域名会有标注。

## 允许域名

这里的域名永远不会被屏蔽：你的网站、文档、合作伙伴。允许域名优先于所有屏蔽域名以及 [新成员链接限制](/zh-Hans/enforcement)。输入域名并点击 **允许**。

<Tip>
  在收紧链接规则之前，先把官方链接加入允许域名，这样机器人就不会删除你自己的公告。
</Tip>

## 合集

collony.ai 替你维护的列表。开启一个合集，选择命中后的操作，并添加你自己的条目。

| 合集 | 拦截内容 | 默认操作 |
| --- | --- | --- |
| **Known scam sources** | 在其他社区转发帖子和快拍时被证实为诈骗的用户和频道 | 删除 + 禁言 |
| **Crypto scams** | 虚假空投、钱包盗取器、保证收益和“资金恢复”骗局 | 删除 + 禁言 |
| **Contact-me / DM scams** | 假客服、“私信我获取帮助”、付费信号 | 删除 |
| **Adult spam** | 成人内容推广以及直播或交友垃圾链接 | 删除 + 禁言 |
| **Link shorteners** | 隐藏真实地址的短链接，常被用来逃避审核 | 删除 |
| **Slurs** | 种族、民族、恐同、恐跨和歧视残障的辱骂词，包括变体拼写 | 删除 |

每个合集显示其生效条目、其中有多少是你添加的、最近 7 天的命中次数以及命中最多的条目。

### 你的条目

向任意合集添加你自己的 **词语**、**短语** 或 **域名**，并设置单独的操作，或点击 **导入文件** 一次添加多个。用 **移除** 删除条目。

**collony.ai 条目** 列表显示 collony.ai 在该合集中维护的内容。任何合集都可导出为 JSON、CSV 或 TXT。
