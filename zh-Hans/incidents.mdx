事件页面列出当前项目中的所有管理案例，无论来自机器人还是你的团队。你可以在这里检查机器人的决定、处理它标记给你的案例，以及处置屡犯者。

在顶部选择时间范围：24h、7d、30d，或点击 **更多** 选择预设或自定义起止日期。可在卡片 **动态** 和 **表格** 之间切换。

## 概要

- 事件数和已执行操作，以及与上一周期相比的变化
- 删除、禁言和封禁的数量
- **每日事件**，按处理方式着色：封禁、禁言、删除或未处理
- **按类型**：每个案例由什么拦截，例如 AI、Instant guard、屏蔽列表或 Surge Guard，以及各自的删除、禁言和封禁数量

## 事件标签

### 筛选器

| 筛选器 | 选项 |
| --- | --- |
| **显示** | 全部事件、待审核、生效中、已原谅、collony.ai 误判 |
| **类型** | AI、Instant guard、屏蔽列表、Surge Guard，以及该时间范围内有过操作的其他防护层 |
| **严重程度** | 严重、高、中、低 |

### 待审核

机器人希望你确认的案例，位于列表顶部。例如机器人无权自行封禁时出现的 **建议封禁**（参见 [处罚与过滤](/zh-Hans/enforcement)），或被屏蔽列表、冒充检测标记的消息。

每张卡片显示成员、频道、拦截来源、违反的规则、机器人的理由、消息内容和已执行的操作。如果机器人判断正确，点击 **标记为已审核**，或打开菜单进行处理。可以选中多张卡片一起标记。

### 事件操作

| 操作 | 作用 |
| --- | --- |
| **按机器人建议封禁** | 按机器人的建议移除成员 |
| **标记为已审核** | 机器人判断正确，不做任何更改。 |
| **原谅** | 撤销已执行的操作并解除禁言或封禁。该事件不再计入 [屡犯封禁](/zh-Hans/enforcement)。 |
| **标记为误判** | 撤销所有操作，并让 collony.ai 学会不再这样做。你可以描述哪里出了问题。 |

菜单中还有禁言、删除消息，以及打开事件、消息或成员的链接。

你也可以在聊天中使用 `/forgive` 和 `/fp` 原谅或标记误判。参见 [聊天命令](/zh-Hans/chat-commands)。

## 违规者标签

按时间范围内的事件对成员分组，显示事件数、最近一次事件、当前状态和机器人的建议，例如 **封禁（机器人请求）**。可直接在行内操作：打开成员、禁言、封禁或加入白名单。已封禁的成员默认隐藏，可以选择显示。

## 事件详情页

点击 **打开事件** 查看完整案例：

- **消息** 及其情绪分数，可翻译，也可在 Telegram 或 Discord 中打开
- **发生了什么**：每项触发的检查及其分数
- **聊天上下文**：前后的消息
- **时间线**：消息发送时间以及机器人每次操作的时间
- **事件**：状态、严重程度、拦截来源、规则和机器人的理由
- **collony AI 分析**：违规分数和恶意分数
- **用户**：成员的记录、状态和角色，以及快速设置角色的按钮

**操作** 菜单可以禁言、封禁、删除最近消息或打开成员资料。
